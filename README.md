# A tool to convert iconpack.apk to mtz 

Dont distribute the mtz if the original apk is proprietary.

for spec.py, pr welcome

## How to use

0. pip install androguard numpy Pillow

1. copy ur perferred iconpack.apk, apks or xapk to the main directory

2. run main.py

3. choose ur target apk/apks/xapk via enter the num than press enter.

4. install the generated mtz file and apply.
